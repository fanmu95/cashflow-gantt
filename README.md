# 💰 资金计划甘特图（现金流日历）

一个纯前端的个人资金计划工具：在日历上填写预计入账 / 花费，自动计算每日累计剩余，负余额日期整格标红预警。单文件、零依赖、离线可用。

## 功能特性

- **日历甘特视图**：按周排列的月历，每格显示当日入账(+绿) / 花费(-红) / 净额 / 累计剩余
- **点击填数**：点击任意日期，添加、编辑（含调整日期）、删除当天的收支项目
- **负余额预警**：累计剩余为负的日期整格红底 + ⚠ 标记，并在详情弹窗给出提示
- **悬停预览**：鼠标悬停日期即可快速预览当天项目清单与累计剩余
- **明细表**：底部汇总全部项目（按日期排序），支持类型 / 月份筛选，合计行自动更新，可直接编辑 / 删除
- **周期账单**：设置每月 / 每周 / 每两周规则，浏览到对应月份自动生成（如房贷、车贷）
- **回收站**：删除的项目保留 30 天，可恢复或彻底删除
- **Excel 导出**：一键把当前筛选结果导出为 `.xlsx`（纯本地生成，无需联网）
- **深浅色主题**：一键切换，选择会记住
- **云同步（可选）**：数据可上传到你的 GitHub Secret Gist / 私有仓库，多设备共享

## 快速开始

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

> 也可以放到任意静态服务器 / GitHub Pages 上访问。

## 数据存储与隐私

- 所有数据保存在**浏览器本地（localStorage）**，不上传任何服务器
- 「导出 / 导入」可备份为 JSON 文件
- 云同步功能需要你自己提供 GitHub Token，数据只存于你的私密 Gist；Token 仅保存在本机浏览器，不会写入数据文件
- 页面不含任何个人数据，账单数据完全由使用者自行录入

## 技术说明

- 单文件 HTML（HTML + CSS + 原生 JavaScript），无任何外部依赖、无构建步骤
- 图表为原生 SVG 绘制，Excel 导出为纯 JS 实现的 ZIP + OOXML 生成器，均离线可用
