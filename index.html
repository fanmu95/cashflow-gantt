💡 使用说明：① 点击任意日期，像普通账目一样填入你的入账 / 花费项目（手头的本金就直接记一笔「入账」即可，程序只做累加，不再有内置的期初余额）；② 鼠标悬停日期可快速预览当天项目与累计剩余；④ 每天的格子会显示：入账(+绿) / 花费(-红) / 当日净额 / 累计剩余；⑤ 当累计剩余为负时，当天背景整格标红并显示 ⚠；⑥ 「导出 / 导入」可备份数据到 JSON 文件；⑦ 点击任意日期打开详情，用 ✏️ 可编辑项目并调整日期；⑧ 🎯 可选：在日期详情里记录「当天实际账户余额」，用于对比计划与实际的偏差（日历格显示「实+/-」，走势图叠加蓝色实际点，顶部卡片显示最近偏差）；⑨ 🔁 周期账单某期如需提前 / 延后（如提前还款），在详情里用 ✏️ 把该笔改到实际扣款的日期即可，原日期本期不再重复生成；⑩ 🟠 有些费用可能最终不会发生：新增项目时勾选「暂不计入收支」（或事后勾选项目后的「不计入」勾选框），该项目显示为橙色、不影响余额计算，顶部卡片和底部合计会单独列出未计入的笔数与金额；⑪ ☁️ 云同步：点右上角 ☁️ 输入你的 GitHub Token（页面不携带任何密钥，Token 仅缓存在本机浏览器），勾选「自动同步」后每次打开页面都会定时上传 / 拉取，换设备用同一 Token 即可继续。
